# Bitshares Price Feed Grapher

Search for and the plot the price feed of any MPA on Bitshares, however far back you want.

Uses kibana for data, and may take several seconds to load.  (Button-mashing *not* recommended.)

Still in development, the search dropdown interface is less than smooth, but it works.  Also on that note, for some reason the websocket connection fails with a 1006 error and the page "loads" forever.  Refreshing the page seems to fix it.
